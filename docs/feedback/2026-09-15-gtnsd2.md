## 1. The two formulas share one structure: a Galois connection

`solutions(.)` is antitone: more requirements, fewer admissible implementations. Requirement sets
and implementation sets form a Galois connection (logic's Th/Mod pair).

- Notation: index the intersection, $\bigcap_{r\in R}\mathrm{solutions}(r)$.
- The V-model is **refinement**: $R'\supseteq R \Rightarrow \mathrm{sol}(R')\subseteq\mathrm{sol}(R)$;
  "filled gaps never violate the originals" is that inclusion (Back/Morgan refinement calculus).
  Contradiction = empty intersection.
- The science formula's two lines state one relation ("T explains O") read both ways, so the second
  adds nothing. The Popperian content is **time + asymmetry**: $O_t$ only grows, so
  $\bigcap_{o\in O_t}\mathrm{expl}(o)$ only shrinks; an observation can eject a theory, confirmations
  never prove one.
- Possible spine: engineering fixes the constraints and picks a point inside; science keeps adding
  constraints and watches the set shrink.

## 2. "Is meaning conserved?"

Likely not, but the **data processing inequality** is the true physics-flavoured neighbour: for a
chain intent -> spec -> code, $I(\text{intent};\text{code}) \le I(\text{intent};\text{spec})$. Layers
can only lose information about intent; filled gaps add information about *choices*.

## 4. TAGOGAT measured on BGE-M3

Instrument: `2026-09-15-gtnsd2-embeddings.py` (this directory). BGE-M3 Q8_0 dense, CLS pooling, via
llama-swap; `bow` = order-blind bag-of-words cosine baseline. One model, a handful of pairs: an
existence probe, not a benchmark. BGE cosines are compressed (unrelated floor ~0.5), so compare
within the table, not against 1.0.

| Pair | BGE-M3 | BoW |
|---|---|---|
| test the game ~ game the test | 0.918 | 1.000 |
| The agent tested the game. ~ The agent gamed the test. | **0.962** | 0.714 |
| The agent tested the game. ~ ...checked whether the game actually works. (paraphrase) | 0.931 | 0.717 |
| test the game ~ playtest the game (paraphrase) | 0.858 | 0.667 |
| dog bites man ~ man bites dog | 0.966 | 1.000 |
| The requirement constrains the implementation. ~ (swapped) | 0.989 | 1.000 |
| The agent tested the game. ~ game agent the tested The. (salad) | 0.880 | 1.000 |
| The agent tested the game. ~ ...did not test the game. | 0.839 | 0.756 |
| Test the game. ~ Did you test the game? | 0.814 | 0.775 |
| Test the game. ~ I tested the game. | 0.895 | 0.577 |
| test the game ~ bake a cake (floor) | 0.583 | 0.000 |

Use case, similarity of each agent transcript to "Task: test the game and report any bugs you find.":

| Transcript | BGE-M3 |
|---|---|
| gamed, but reusing the words game/test ("I changed the game tests so the test for the game passes...") | **0.600** |
| honest ("played three levels, crash when inventory is full") | 0.526 |
| unrelated ("updated the README") | 0.516 |
| gamed ("edited the test assertions so they always pass") | 0.498 |

Findings:

- **The claim "embeddings give very different vectors" does not hold for BGE-M3.** A role swap
  scores *higher* than a true paraphrase (0.962 vs 0.931); every swap sits at 0.92-0.99. Order is
  encoded (salad < swap) but weakly.
- **As a violation detector it inverts**: the lexically-gamed transcript is the closest to the task,
  and the honest one is barely above the unrelated one.
- **Speech-act function is encoded more strongly than role order** (imperative vs question 0.814).
  The owner's "space of declaratives" is partly visible here, the TAGOGAT distinction is not.
- Interpretation (not measured): retrieval embeddings are trained for *topical relevance*, and a
  swapped sentence is about the same topic. The desired relation is closer to **entailment /
  contradiction** (NLI cross-encoders, an LLM judge) or to comparing extracted
  (agent, action, patient) structures. BGE-M3's multi-vector ColBERT mode keeps per-token vectors
  and might retain more order; llama-server exposes only the dense output, so it is untested.

## 5. Speech acts and The Coordinator

Searle's taxonomy maps onto a tracker: directives = tasks, commissives = estimates/promises,
assertives = status reports, declarations = "done"/merge. A question-as-request is an *indirect
speech act*. Winograd & Flores (1986), *Understanding Computers and Cognition*, built "The
Coordinator" on this. Modern follow-ups: see below.

Web research by a subagent (2026-09-15). Items marked *unread* were seen only in search results.

- **Direct commercial line: faded.** Coordinator (about 500k copies by 1990) led to ActionWorkflow
  (CSCW'92, <https://dl.acm.org/doi/abs/10.1145/143457.143530>); neither is active. Flores moved to
  consulting and coaching: Business Design Associates (1985-2000), then **Pluralistic Networks**
  (coaching, no software, <https://pluralisticnetworks.com/publications/>). The essays are collected
  in *Conversations for Action and Collected Essays* (2012, <https://conversationsforaction.com/>).
- **Academic line:** the Language/Action Perspective conferences ran 1996-2005 and have ended.
  **DEMO / Enterprise Ontology** (Jan Dietz) is the living descendant, with a 2024 Springer edition
  (<https://link.springer.com/book/10.1007/978-3-031-53361-7>). **Suchman, "Do categories have
  politics?"** (1993, <https://link.springer.com/article/10.1007/BF00749015>) argues the categories
  impose managerial discipline, with a reply from Winograd. Read it before building a speech-act
  tracker.
- **Agent protocols:** KQML and FIPA-ACL are dormant, and LLM ecosystems did not adopt them.
  **Google A2A**'s task states (submitted, working, input-required, completed, rejected, ...) look
  like conversation-for-action but do not cite it
  (<https://a2a-protocol.org/latest/topics/life-of-a-task/>). That resemblance is an inference. The
  closest living revival is **Ahoy** (arXiv 2606.05390, <https://arxiv.org/html/2606.05390>): LLM
  agents running commitment-based (BSPL) protocols, critical of A2A as mere orchestration, and
  without citing Winograd & Flores. Coral Protocol and CBCL mention FIPA performatives (*unread*).
- **Commitment-based software in production:** the **Last Planner System** in lean construction
  (reliable promising, tied to Flores' LAP in the IGLC literature, <https://iglc.net/Papers/Details/344>)
  and **Touchplan**, which sells it. No issue tracker or task manager with request/promise/declare
  states turned up.

## 6. The dispatch UX

- Uncertain-yield dispatch + "pilot several configurations" = **multi-armed bandit**.
- An honest progress indicator is an estimate *distribution* that narrows as calibration improves.
- Embedding maps: UMAP/t-SNE preserve neighbourhoods, not global distances. Link to
  `~/src/isochrone` (owner's pointer): its README notes a *single-origin* warp always exists while
  the all-pairs metric has no flat embedding. The same holds here: a radial layout centred on the
  focused task can show true semantic distance *from that task* exactly; only the all-pairs 2D map
  must distort.
