== 2. WHAT TRANSFORM IS THIS? ==

Exact algebra (verified numerically below): define the COMPLEX state
    z(t) = x(t) + i*x_t(t)/omega,   so   e(t) = (omega^2/2)*|z(t)|^2.
Both channels are linear filters of y, so z = h_c * y exactly, with
    h_c(t) = h_x(t) + (i/omega) h_x'(t)
           = (omega^2/Omega) e^{-beta t} [ c_- e^{-i Omega t} + c_+ e^{+i Omega t} ],
    c_- = (i/2)(1 + e^{i gamma}),  c_+ = (-i/2)(1 - e^{i gamma}),
    gamma = atan2(beta, Omega)  (note Omega + i*beta = omega e^{i gamma}).
So the resogram is EXACTLY |CWT|^2 for a causal complex kernel that is a
damped complex exponential plus a counter-rotating leak of relative
amplitude |c_+/c_-| = tan(gamma/2) ~ 1/(4Q).

     Q     tan(gamma/2)   1/(4Q)    measured |c+/c-|   |e - (om^2/2)|h_c*y|^2| rel
     5.0      0.05013   0.05000          0.05013       4.89e-16
    20.0      0.01250   0.01250          0.01250       4.56e-16
    80.0      0.00313   0.00313          0.00313       4.82e-16

Admissibility (zero mean) is what a wavelet needs and this kernel lacks:
  H_x(0) = 1 while the peak gain is Q, so the DC leak sits at -20log10(Q) dB.
     Q     DC gain   peak gain   DC leak [dB]   measured [dB]
     5.0    0.9987       5.000         -13.98          -13.99
    20.0    0.9987      20.000         -26.02          -26.03
    80.0    0.9987      80.000         -38.06          -38.07

Kernel identity check against the order-1 gammatone
  gammatone_n(t) = t^{n-1} e^{-2 pi b t} cos(2 pi f_c t + phi) u(t)
  with n=1, 2 pi b = beta, 2 pi f_c = Omega, phi = -pi/2 this IS h_x/(omega^2/Omega).
  max rel deviation h_x vs order-1 gammatone: 4.31e-10
